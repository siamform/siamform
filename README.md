### ✦ 流儀 — how I build

- Start from the problem and the people using it; structure before styling.
- Strict data model and validation, so the interface can stay simple.
- Performance, accessibility and reduced motion are part of the design.
- Secrets stay out of the code; builds and checks are automated.
- Ship small working steps, improve from real feedback.

> 「上手くいくまで、何度でも」 — keep going until it works.
