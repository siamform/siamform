## About

I work on the whole path of a product: concept and layout, typography and motion, then the data model, authentication, APIs and deployment behind it. Most of my work is in the JavaScript and TypeScript ecosystem, with Next.js and React at the center. I also build an open-source Android app, Yumeiro, in Kotlin.

## How I build

- Start from the problem and the people using it, then decide the structure before the styling.
- Keep the data model and validation strict, so the interface can stay simple.
- Treat performance, accessibility and a reduced-motion version as part of the design, not an afterthought.
- Keep secrets out of the code, review dependencies, and automate builds and checks.
- Ship in small, working steps and improve from real feedback.
